# Translations (i18n)

* **Source language: English.** Every user-visible string in Rust (`tr!`, `trn!`, `n_`) and in the
  bridge (`_()`) is an English gettext id. `po/uk.po` carries the Ukrainian texts (the interface was
  Ukrainian-only before stage 1.5, so nothing changes for a Ukrainian user). English needs no
  catalogue: the ids are shown as they are.
* **One gettext domain, `desktop-themes-rs`,** for the `themes` window/CLI/D-Bus service, deskd, the
  GSettings schema, the bridge extension and the `.desktop`/metainfo files.
* **Language setting** `io.github.OlehDzhumyk.Desk language` (`system` | `uk` | `en`; window:
  Features → General). `system` follows the session (LANGUAGE, LC_MESSAGES). `uk`/`en` override it
  for this project only: the Rust programs re-execute themselves once with `LANGUAGE` set
  (`desk_settings::i18n::init`) and give child processes the user's own `LANGUAGE` back; the bridge
  uses `locale/<lang>.json` (built from `po/<lang>.po`) instead of the shell's locale. The
  environment variable `DESKTOP_THEMES_LANGUAGE` overrides the setting (tests, screenshots).
  `data/install.sh` sets `language='uk'` once when it upgrades an install from before the setting,
  so a Ukrainian user on an English session keeps the Ukrainian interface.
* **Placeholders** are named: `tr!("Theme “{name}” applied", name = n)`, `fmt(_('{n} min ago'), {n})`.
  Translations must keep them (`msgfmt --check` for Rust strings, the i18n lint test for all).

## Workflow

```sh
cargo xtask pot          # xgettext (Rust, TypeScript, desktop, metainfo) → po/desktop-themes-rs.pot,
                         # msgmerge into po/*.po
$EDITOR po/uk.po         # translate new/changed entries, remove "fuzzy"
cargo test -p desk-settings --test i18n_lint
```

Install: `data/install.sh` compiles `po/*.po` into `~/.local/share/locale/<lang>/LC_MESSAGES/` and
merges the translations into the `.desktop` and metainfo files; `bridge/assemble.mjs` puts `.mo` and
`.json` catalogues into the extension. Development builds find catalogues through
`DESKTOP_THEMES_LOCALEDIR`.

Adding a language: `msginit -i po/desktop-themes-rs.pot -l de -o po/de.po`, translate, add the code to `po/LINGUAS`, add the
value to the `language` choices in `crates/desk-settings/src/registry.rs` (`cargo xtask gen`) and to
`language_env` / the bridge's `setLanguage`.

Not translated: clap's own help headings ("Usage:", "Print help"), journal/log lines of deskd and
the `apply.log` format.
